# Breezeline GitHub Pages Website

Upload index.html, style.css, support.html, .nojekyll to the root of one GitHub Pages repository. Extract each of the 10 article ZIP files and merge their `articles/` folders into the same repository. Do not upload the ZIP files directly. Homepage intentionally does not list articles. Each article has its own URL at `/articles/<slug>.html`. This is an independent informational site, not an official Breezeline service. Review all content before publication.
